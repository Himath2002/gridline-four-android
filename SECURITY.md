# Security policy

## Supported version

Security fixes are applied to the latest published release and `main`.

## Reporting

Please use GitHub's private vulnerability reporting for issues involving malformed state, unexpected data retention, dependency risk, or application crashes. Do not publish exploit details in a public issue before a fix is available.

Gridline Four requests no network permission, stores profiles only in memory, and explicitly disables application-data backup. No service credentials or signing material belong in the repository.
